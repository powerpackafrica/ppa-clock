# PPA Clock (tablet page)

Staff clock-in/out page for Power Pack Africa. Runs in the browser of the reception tablet.

- Page: https://powerpackafrica.github.io/ppa-clock/
- Cards: QR code `PPA<6 digits>-<4 chars>`; face recognition is optional (the card always works).
- No personal data is stored in this repository. Records, photos and face data are kept in the company's Google Drive.
- The tablet needs a one-time setup link (kept by HR); without it the page does nothing.

Files: `index.html` (app), `sw.js` (offline support), `manifest.json`, icons.
